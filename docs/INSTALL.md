# Installation
1. `chmod +x XBlades-Linux-x86_64.AppImage && ./XBlades-Linux-x86_64.AppImage`
2. Au premier lancement, cliquer « Autoriser l'accès » (mot de passe une seule fois : règle udev `70-xblades.rules`).
3. Désinstaller : onglet Diagnostic > « Désinstaller l'accès », puis supprimer l'AppImage. Sauvegardes : `~/.local/share/xblades/`.
